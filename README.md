# Student Performance Predictor

A Machine Learning web application that predicts a student's final marks using study hours, attendance, and previous marks.

## Features
- Predicts estimated final marks
- Uses Linear Regression
- Displays model evaluation using Mean Absolute Error (MAE)
- Interactive interface built with Streamlit

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Streamlit

## Run Locally
1. Clone this repository.
2. Install the dependencies listed in `requirements.csv` after verifying the file format.
3. Run the application:
   `streamlit run app.py`

## Dataset
The project uses `students.csv` as its sample dataset.

## Disclaimer
Predictions are estimates for educational purposes and are not guaranteed actual exam results.
